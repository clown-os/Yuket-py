# 雨课堂本地刷课工具（Python 版）

用 Playwright 驱动真实 Chrome，把 [yuketang-jiaoben](https://github.com/Niuwh/yuketang-jiaoben) 的油猴脚本功能搬到本地，
并增加了：

1. **微信扫码登录 + 登录态保存**；
2. **课程列表选择**（可多选，编号或课程名）；
3. **直接使用网站自带的「未完成」列表刷课**，不扫描目录、不展开批量；
4. **进入视频先看完成度：未完成就从 00:00 完整播放一遍**；
5. **4 个标签页并行刷**（可配置 1~8），刷完自动在同一个标签页进入下一个视频；
6. 视频播完后再检测完成度；仍未完成才整段重播一次（最多 2 遍）；
7. **「未完成 → 作业」AI 答题**：逐题截图 + 视觉模型（默认 GLM-5.3-Flash），
   自动点选项、提交；作业页若触发「安全核验」，会等待你在浏览器里手动完成。

## 一、使用

```bat
cd D:\My-project\yuketang-python
pip install -r requirements.txt
python main.py
```

或双击 `run.bat`（会自动 `pause`，窗口不会一闪而过）。

流程：

1. 首次运行会打开雨课堂登录页，用微信/雨课堂 APP 扫码；登录态保存在 `browser_data/`，以后直接复用。
2. 进入课程中心，程序列出账号下所有课程：
   ```text
   [ 1] 体测Ⅱ 张旭 2026秋-体测Ⅱ165
   [ 2] 马克思主义基本原理 安广兴 2026秋-马克思主义基本原理55
   ...
   [ 9] 数据结构与算法 郭丁丁 2026秋-数据结构与算法03
   ```
   输入编号（可多选，如 `9,10`）或课程名（如 `数据结构与算法`）；直接回车 = 全部课程。
3. 程序进入课程页，点击网站自带的 **「未完成」** 标签，再切到 **「视频」** 筛选。
4. 按 `workers`（默认 4）开多个标签页并行：每个视频进入后先看完成度，
   未完成就从 00:00 完整播放；播完检测，完成则在同一标签页通过左侧目录进入下一个。
5. 一门课处理完，自动回到课程中心处理下一门已选课程。

也可以跳过选择，直接指定课程：

```bash
python main.py --url "https://www.yuketang.cn/v2/web/studentLog/123456"
python main.py --course-id 123456
```

验收/只刷两个视频：

```bash
python main.py --max-items 2
```

## 二、单个视频的处理流程（重要）

```text
打开视频（直接使用 ai-workspace 视频地址，不返回上级列表）
  ↓
先读取顶部“完成度：xx%”
  ├─ 已完成 → 直接下一个
  └─ 未完成 → 进度拖回 00:00 → 完整播放一整遍
                 ↓
              播放到结尾
                 ↓
              检测完成度（最多等 30 秒）
                 ├─ 已完成 → 下一个
                 └─ 未完成 → 重新加载 → 再次从 0 完整重播（第 2 遍）
                                 ↓
                              再检测
                                 ├─ 已完成 → 下一个
                                 └─ 未完成 → 记录失败 → 下一个
```

- 每个视频最多播放 **2 遍**（第一遍就是从头完整播；只有仍未完成才重播一次），由 `[replay] max_attempts` 控制；
- 播放过程中不会反复 seek，不会死循环；
- 顶部完成度达到 100%/已完成即判定完成；不需要返回课程目录页。

## 二点五、并行刷课

`[playback] workers = 4` 表示同时开 **4 个标签页**播放 4 个视频：

- 不是 4 个 Python 线程（Playwright 的同步 API 跨线程不安全），而是同一浏览器里 4 个独立播放页；
- 效果相同：4 个视频同时计时、同时推进；
- 每个标签页刷完一个视频后，**在同一个标签页**优先点击左侧目录里的下一个视频；
  目录里找不到时直接加载该视频地址。全程不回到上级课程列表；
- 网络带宽不足时可把 `workers` 调成 2 或 1。

## 三、配置（config.ini）

首次运行会自动从 `config_template.ini` 生成 `config.ini`。

```ini
[playback]
speed = 2                 ; 播放倍速
mute = true               ; 静音
workers = 4               ; 并行标签页数量（1~8）
completion_timeout = 30   ; 播完后等待平台“已完成”的秒数
stall_timeout = 45        ; 播放进度停滞多少秒判定卡住
start_over = false        ; 仅旧路线回退时使用；未完成列表流程始终从 0 播放

[replay]
enabled = true            ; 播完未完成 → 整段重播
max_attempts = 2          ; 每个视频最多播放次数（含第一次）
reload_on_retry = true    ; 重播前刷新播放器
stop_on_fail = false      ; 仍失败时：false=记录并继续，true=停止

[browser]
headless = false          ; 首次登录必须 false
channel = chrome          ; chrome / msedge
proxy =                   ; 可选：http://127.0.0.1:7890 或 socks5://127.0.0.1:7891
```

## 四、答题 API / AI 作业

在 `[answer]` 中启用，支持：

- `openai`：任意 OpenAI 兼容 `/chat/completions`（智谱 GLM、OpenAI、Qwen、硅基流动等）；
- `anthropic`：Anthropic Messages API；
- `custom`：你自己的 HTTP 接口，POST `{"question": "...", "options": [...], "image": "data:image/png;base64,..."}`，返回 `{"answer": "A"}`。

### 视觉答题（推荐）

雨课堂作业的题干/选项经常是图片或自定义字体，纯文本模型读不出来，所以默认把**题目截图**发给视觉模型：

```ini
[answer]
enabled = true
homework = true
vision = true
provider = openai
api_url = https://open.bigmodel.cn/api/paas/v4/chat/completions
api_key = 你的key
model = glm-5.3-flash
auth = bearer
timeout = 180
max_retries = 2
auto_submit = true
```

已确认 `glm-5.3-flash` 支持图片输入（原生多模态，OpenAI 兼容 `image_url` 内容块）。
程序会：

1. 进入「未完成 → 作业」，打开题目 iframe；
2. 逐题截取题干 + 选项图，发给模型；
3. 选择题解析 `正确答案：A/B/C/D`；填空题/简答题输出文本填入输入框；
4. **雨课堂是逐题提交**：每答完一题就点一次底部「提交」，题号变绿/打勾；
5. 全部题目都提交后，用「未完成」列表复核，条目消失即完成。

> 注意：底部「提交」按钮是**当前题**的提交按钮，不是整卷提交；
> 本次已按逐题提交实现。只要有题目没答完/没提交，程序不会继续点提交，也不会误报完成。

### ⚠️ 作业页的安全核验

作业页可能弹出雨课堂的 **「安全核验」**（按顺序拖动起点 → 1 → 2 → 3 → 终点的验证码）。
工具**不会绕过**它：

- 有界面模式（`headless = false`）：程序会暂停并提示，你在浏览器里手动完成验证，
  完成后自动继续（最多等 5 分钟）；
- 无头模式：无法完成验证，会跳过作业并提示。

视频刷课不受影响；只在处理作业时可能遇到。

### 只做作业 / 不做作业

```bash
python main.py --homework-only   # 只做未完成作业
python main.py --no-homework     # 只刷视频
python main.py --homework-only --homework-index 2   # 只做第 2 个未完成作业（测试用）
python main.py --homework-only --no-submit          # 只作答、不逐题提交（人工复核）
```

未配置 API 时作业会自动跳过，不影响视频。

## 六、常见问题

**视频加载失败：无法连接视频 CDN**
- 视频文件在 `ali-cdn.xuetangx.com`，部分校园网/运营商网络会连接超时或返回 `MEDIA_ELEMENT_ERROR`；
- 打开本地代理后配置 `[browser] proxy`，例如 Clash：`http://127.0.0.1:7890`；
- 程序会自动重新打开该视频重试 2 次，仍失败才停止，不会死循环。

**「未完成」里没有视频 / 列表为空**
- 确认课程页顶部有「未完成」标签；
- 程序会自动点击「未超时」和「视频」筛选；
- 如果课程是旧版 UI，会回退到目录模式。

**第一次运行浏览器一闪而过**
- 通常是登录未完成或没有课程被选中；请从终端运行（或双击 `run.bat`）查看日志；
- 日志文件在 `logs/` 下。

**手动点开了别的视频**
- 工具只会控制它为当前队列打开的视频页；不会再把你手动打开的视频拉回开头。

## 八、测试

```bash
python tests/e2e_smoke.py
```

覆盖：登录等待、课程目录/批量、视频播完未完成整段重播、目录级复核、答题接口。

真实环境验收（2026-10-29，账号课程「数据结构与算法」）：

- 课程中心读取到 27 门课程；
- `07C-2 平均高度`：86% 进入 → 从头完整播放 → 已完成，并从「未完成」列表消失；
- 2 个标签页并行：`10b2-1: 上滤` 与 `10b4-3: 自下而上的下滤：算法` 同时开始，
  各自从头播完并完成，耗时约 2 分 50 秒（单个视频 4~5 分钟）；
- 4 个标签页并行：4 个视频同时从头播放，全部在第一遍就完成，总耗时约 4 分钟；
- 同一标签页自动下一个：`W4` 完成 `02B1-4` 后直接在其标签页打开 `02B2`，
  `W3` 完成 `02B1-2` 后直接打开 `02C1-3`，全程没有返回课程列表；
- 左侧目录切换：`W3` 完成 `02D1-1` 后点击左侧目录进入 `02D1-3`，
  `W2` 完成 `02C4` 后点击左侧目录进入 `02D1-4`，均在同一标签页完成；
- 6 个视频、4 个标签页，总耗时约 5 分钟，全部在第一遍完整播放后完成，无重播。

视频 CDN 偶发超时属于网络问题，配置 `[browser] proxy` 即可；程序本身不会因此循环。
